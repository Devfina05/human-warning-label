Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. Five equal rewards, free entry, 72 hours open.

The label this program writes to `/output/entry.txt`:

> WARNING: This human contains exactly one (1) brain cell, and it is currently out to lunch.

One idea, one read, punchline in the last words — the brain cell is not missing, it is just out to lunch.

## Run it

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (creating `/output` if needed) and prints it with its character count. No input, no network, deterministic: every run writes byte-identical output.
